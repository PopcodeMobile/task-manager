## Material unknowns / acceptance decisions

1. Actual named route count is 21, as noted above. Track 404 explicitly without
   fabricating a route. Saved-view tests remain separate from eight built-ins.
2. No exhaustive visible mutation tests exist for most routes/tabs. Existing
   route smoke passes cannot prove calendar/timeline drag, archive restore,
   saved views, bulk actions, all settings or mobile/keyboard parity.
3. This inventory did not run browser tests or verify environmental availability.
   Cloud/Auth fixture gates must be satisfied before claiming those tests pass.
4. Some preference controls may store a choice without a fully implemented
   consumer. Preserve their current visible/persistence behavior; confirm actual
   launch-page/default-view effects before promising additional behavior.
5. Normal legacy navigation does not encode project/tab IDs in URL. The approved
   Task 5 URL migration must define those deep links and test reload/back; source
   inventory alone cannot supply an existing canonical URL contract.
6. Real uploads, invitations, billing/security demonstrations, project privacy
   and local integration limitations retain approved boundaries. Their visible
   local demonstrations must not become simulated cloud success during parity.

states, local/personal persistence and existing browser workflow intentions are
recorded with visible acceptance scenarios. Frontend implementation waits for
root's Task 4/4a review gates.
