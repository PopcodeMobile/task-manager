# Custom branding, 2026-10-21

## Delivered behavior

Appearance accepts a native color picker or complete #RGB/#RRGGBB input. Apply persists the original base HEX per identity on this device. Runtime variants preserve readable accent text on existing surfaces and tinted avatar backgrounds; presets remove the custom overrides. Invalid input and save failures remain inline.

Organization settings accept PNG, JPG or WebP up to 2 MB. The editor decodes and normalizes to a bounded WebP thumbnail, previews before Save, and supports Undo, replacement and removal. Human owners/admins manage the shared logo; members can read it. Upload errors retain the selection and give a specific safe message. The picker/sidebar uses the saved logo, with the existing fallback when unavailable.

Cloud workspaces store only a scoped `logoPath` in the private `organization-logos` bucket. Reads use authenticated SDK downloads with `cache: 'no-store'`, then a local blob URL scoped to both path and auth-session boundary. Cleanup revokes blob resources. Local demonstrations use a bounded WebP data URI through a separate `logoDataUrl` command that the cloud validator rejects. Removing the pointer preserves previous private objects; lifecycle retention is separate work.
